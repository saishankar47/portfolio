# 🤖 AI Agents Documentation

This folder contains specialized AI agents for maintaining the portfolio.

Each agent has a specific responsibility and follows project conventions.

---

## Available Agents

| Agent | Responsibility |
|--------|----------------|
| Project Update Agent | Add, update, remove projects |
| Experience Update Agent | Manage work experience |
| Skills Update Agent | Maintain skills section |
| SEO Agent | Update metadata and SEO |
| UI Agent | Maintain consistent UI/UX |
| Deployment Agent | Prepare production deployments |
| Code Review Agent | Ensure code quality and standards |

---

## Goals

- Keep the codebase consistent
- Avoid duplicate logic
- Follow project architecture
- Preserve design system
- Maintain SEO
- Keep documentation updated
